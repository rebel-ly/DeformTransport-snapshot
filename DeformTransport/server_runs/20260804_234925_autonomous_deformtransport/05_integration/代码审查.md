# Transport 集成代码审查

审查范围：`infer_sim.py`、`deform_transport/pipeline_integration.py`、`vidgen/pipeline_sdedit.py` 及对应单元测试。只读审查，不修改用户现有源码。

## 结论

静态调用链成立：transport latent 在 `infer_sim.py:277-286` 替换 freshly encoded `sim_latent`，随后在 `vidgen/pipeline_sdedit.py:186-216` 通过 scheduler `add_noise` 进入 SDEdit 初始化。Baseline 未传 artifact 时保持原路径。

但当前集成还不能安全支撑 Correct/Shuffled 科研结论，存在三个优先级 P1 的 provenance/时序缺口。

## P1：同 shape 的错误案例 artifact 可静默进入生成器

`deform_transport/pipeline_integration.py:49-55` 只比较 shape、浮点类型和有限性。它没有校验 case 名、输入文件 hash、checkpoint hash、seed、时序定义或 target latent hash。代码注释 `:27-30` 声称可防止不同 case，但实际实现无法识别同 shape 的另一案例。

对应测试 `tests/test_pipeline_integration.py:45-53` 名称包含 case mismatch，实际只把时间长度从 2 改为 3；没有构造同 shape 的错误 case。因此测试不能支持注释中的保证。

影响：错误 artifact 仍会生成“看似成功”的视频，使整组对照失去科学有效性。

## P1：预融合 tensor 整体覆盖 reference，mask 外也不保证来自本次输入

loader 在 `pipeline_integration.py:76-79` 直接返回历史 `correct_fused_latent` 或 `shuffled_fused_latent` 整个 tensor。虽然 artifact 含 `target_latent`，当前代码没有比较它与本次 freshly encoded `reference_latent`；也没有用本次 reference 在 mask 外重新融合。

影响：即使两者 shape 相同，只要输入 PNG、VAE、resize 或编码精度有差异，mask 外区域也可能被旧 artifact 替换。Correct/Shuffled 与 Baseline 不再只差 transport 对应关系。

最小修复方向：artifact 保存并校验输入/target hash；运行时验证 artifact target 与 reference 的数值或 hash；优先从 transported grid 与本次 reference 重新执行 `torch.where(mask, transported, reference)`。

## P1：`final_sim` coarse 帧数与配置时序未在生成入口强制一致

`infer_sim.py:230-233` 加载任意数量 `frame_*.png`；`infer_sim.py:289-299` 随后把 VAE latent 静默裁剪或重复末帧到 `num_output_frames`；`infer_sim.py:302` 又假设 pixel 帧数为 `4*T-3`。入口没有强制 `len(frames) == 4*num_output_frames-3`。

影响：配置 T、coarse 帧数和 noise 时序错误时，Baseline 也可能继续运行并产生重复/裁剪 latent。外部 CPU validator 已能捕获该问题，但科研入口自身仍缺 fail-fast。

## P2：配置要求 mask 时缺失文件仍继续

`infer_sim.py:237-246` 在 `mask_dropin_step > 0` 且 `points_masks_downsampled.pt` 缺失时只打印 warning 并继续。对固定对照实验，这会把配置错误变成另一种模型条件，而不是明确失败。

## P2：artifact 合同检查仍不完整

- loader 不检查 artifact `format_version`；旧/新语义可能同 shape 混用。
- 不要求 transport mask 非空。
- 不检查 Correct 与 Shuffled 确实不同。
- 不验证 fused latent 在 mask 外等于 target/reference。
- artifact 当前没有可迁移相对路径或内容哈希。

这些检查已部分加入本轮 GPU smoke 脚本，但最终应进入正式 artifact 合同和生成入口。

## P2：测试覆盖与科研保证不匹配

当前 loader 测试覆盖 mode 选择、dtype/device 转换、shape mismatch、非有限值和 mask/count 不一致。尚缺：

1. 同 shape 错误 case；
2. target latent 与 freshly encoded reference 不同；
3. mask 外被历史 fused tensor 改写；
4. 空 mask；
5. format version 不兼容；
6. Correct 与 Shuffled 完全相同；
7. `final_sim` 的 `4*T-3` 时序不一致。

## P3：checkpoint 加载使用裸 `except`

`infer_sim.py:170-174` 的裸 `except` 会把 OOM、文件损坏或其他异常也当作 FSDP key 前缀问题重试，降低失败可诊断性。建议只捕获预期的 `RuntimeError`，并保留第一次异常上下文。该问题不是 transport 新引入，但会影响首次 smoke 审计。

## 建议执行顺序

1. Baseline smoke 不使用 transport，可在完整 `final_sim` 恢复后先验证官方路径。
2. Correct/Shuffled 完整生成之前，先修复 P1 provenance 与时序 fail-fast，并增加对应测试。
3. 再运行同卡串行三组；若只做当前真实 Wan VAE artifact smoke，必须明确其目标是环境/数值验证，不作为生成器集成结论。

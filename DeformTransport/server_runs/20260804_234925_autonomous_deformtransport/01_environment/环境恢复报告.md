# realwonder-gen 环境恢复报告

## 已安装的最小依赖

1. imageio 2.37.4；
2. einops 0.8.2；
3. omegaconf 2.3.0，并带入必需的 antlr4-python3-runtime 4.9.3；
4. peft 0.10.0。

每次安装前均保存 pip freeze 与 pip check，执行 dry-run，并确认不会升级、替换或卸载受保护核心包。

## 受保护核心版本

Torch 2.5.1+cu121、Torchvision 0.20.1+cu121、Torchaudio 2.5.1+cu121、NumPy 1.26.4、Diffusers 0.30.2、Transformers 4.49.0、Tokenizers 0.21.4、Accelerate 1.14.0、SentencePiece 0.2.2，全部保持不变。

## 当前状态

pip check 通过。生成入口不再报告缺失 Python 模块；在 CUDA_VISIBLE_DEVICES 为空时，vidgen/memory.py 会在导入阶段调用 torch.cuda.current_device() 并失败，因此 --help 也必须等待可用 GPU。该问题是入口的 GPU 强耦合，不是依赖缺失。

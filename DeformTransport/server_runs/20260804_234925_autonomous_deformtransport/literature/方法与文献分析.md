# 方法与文献分析

## 当前方法定位

DeformTransport 当前实现把物理模拟中具有持久材料点身份的三维点投影到 Wan latent 网格，再将源帧 latent 依据未来材料点轨迹前向运输。Correct 保留 point ID 对应，Shuffled 打乱对应；两者在同一 transport mask 内替换 coarse latent，mask 外保留原 coarse latent。该机制目前发生在 RealWonder 生成器之前，作为 SDEdit 初始 latent，而不是在每个扩散去噪步重复 warp。

当前最重要的实证问题不是先增加复杂模块，而是验证输入 provenance 是否完全一致、transport 是否确实改变生成器输入、Correct 相对 Baseline/Shuffled 的完整视频结果是否稳定改善。

## 与相关工作的关系

### RealWonder

RealWonder 把动作条件物理模拟与视频生成结合，是本项目的直接生成框架和 Baseline 来源。DeformTransport 不替代它的模拟器或生成器，而是利用模拟中已有的材料点轨迹，为 coarse RGB 编码后的 latent 提供显式对应约束。

来源：<https://arxiv.org/abs/2603.05449>；官方代码：<https://github.com/liuwei283/RealWonder>

### CamProbe / Probing into Camera Control of Video Models

CamProbe 使用位移场在去噪过程中对 latent 做可微重采样，以分析和控制视频模型的相机运动。它对本项目的直接启示是显式几何位移可以进入 latent 去噪链路，但任务语义不同：相机控制主要描述全局视角变化，DeformTransport 追踪的是受动作驱动的非刚性材料点、遮挡和拓扑邻域。当前实现也尚未采用逐去噪步 warp，因此不能把现有结果表述成 CamProbe 的直接复现。

来源：<https://arxiv.org/abs/2605.14815>

### Softmax Splatting

Softmax Splatting 通过带权 softmax 聚合解决前向 warp 中多个源像素落到同一目标位置的碰撞问题。它可作为未来改进 transport 冲突消解的候选，权重可来自深度、可见性或置信度。然而当前硬运输的首要缺口是完整生成验证和输入 provenance，而不是已经证明的碰撞聚合失败；在没有对应消融前，不应提前引入 soft splatting 并增加解释变量。

来源：<https://arxiv.org/abs/2003.05534>

### Latent-Reframe 与 CameraNoise

这类工作进一步说明，相机或几何条件可通过 latent 重排、噪声结构或运动先验影响视频生成。它们适合作为设计空间参照，但不能代替材料点级实验：DeformTransport 的主张必须由相同 checkpoint、seed、coarse 输入、mask 和时序下的 Baseline/Correct/Shuffled 对照支撑。

Latent-Reframe：<https://latent-reframe.github.io/>；CameraNoise：<https://arxiv.org/abs/2605.30774>

## 当前可检验假设

1. 若材料点对应提供有效物理先验，Correct 在运输区域的时序一致性应优于 Shuffled，并且完整生成结果应可重复出现该差异。
2. 若收益仅来自替换一部分 latent，Correct 与 Shuffled 的差距会缩小，而二者可能同时偏离 Baseline。
3. 若压缩视频重建或错误案例 artifact 被误用，即使 shape 完全一致也会产生伪差异；输入文件 hash、目标 latent hash 和案例元数据必须进入 artifact。
4. 若前向碰撞是主要误差源，contribution count 较高区域应与伪影或误差升高相关；只有该相关性成立后，softmax splatting 才成为高优先级改动。

## 实验顺序建议

1. 先运行真实 Wan VAE + artifact GPU smoke，确认当前服务器模型加载、三路解码和数值稳定。
2. 恢复完整且无损的 Santa `final_sim`，锁定其所有输入 hash。
3. 在同一独占 GPU 上串行运行 Baseline、Correct、Shuffled，固定 seed 0 和 generator/EMA 选择。
4. 至少增加 3 个 seed；报告均值、方差、逐帧曲线和失败案例，不只展示最佳帧。
5. 根据 collision count 与误差的相关性决定是否实现 soft splatting；根据 transport 影响衰减情况决定是否探索逐去噪步注入。

## 结论边界

现有静态集成和 VAE proxy 结果只支持 transport 数据结构有效、Correct 与 Shuffled 不同、Correct proxy 误差较低。在完整 RealWonder 三组生成和未来 GT 缺失时，不能声称生成质量提升、物理正确性提升或超过任何外部方法。

# Stage 5: checkpoint-free hard point transport

## Verdict

The minimum hard point-transport operator passes its engineering tests and the
saved 21-frame Santa cloth proxy experiment. Under exactly the same point
trajectories, visible source set, target-valid set, feature multiset, coverage,
contribution counts, and seed, correct point identity is substantially better
than an object-internal shuffled identity assignment at reconstructing the
future RealWonder coarse RGB proxy.

This is positive evidence for persistent point identity as a visual transport
mechanism. It is not evidence about Wan latent behavior, generated future-video
quality, or robot actions.

## Inputs

No simulation was rerun. The probe consumes:

`artifacts/transport_validation/santa_cloth_21f/transport_ready.pt`

The standardized artifact contains:

- 21 future frames and 28,264 stable point IDs;
- 23,921 source-raster-visible points (84.63% of all reconstructed points);
- 1,257 occupied source spatial cells;
- `[21,28264,3]` geometry and `[21,28264,2]` render/latent coordinates;
- exact `[28264,5]` point-particle binding;
- per-frame camera, depth, crop-validity, initial RGB, future coarse RGB, flow,
  and source-raster paths.

The output is derived from the already-verified right-wind Santa trajectory.
Santa is a wind-driven PBD-cloth example, not a robot-action experiment.

## Operator

`deform_transport/hard_transport.py` implements a payload-independent operator:

1. filter source points by raster visibility, source validity, and bounds;
2. read the nearest source cell once for every point ID;
3. retain one source feature per point, including points sharing a source cell;
4. carry that fixed feature through every future point position;
5. filter target points before indexing, with no boundary clamping;
6. accumulate point features with `torch.scatter_add_`;
7. normalize by integer contribution count;
8. keep cells with no contribution at zero with `transport_mask=false`.

No bilinear sampling, Gaussian or softmax splatting, CUDA extension, depth
conflict, dilation, learned feature, multiscale feature, training, or denoising
intervention is present.

`mode=shuffled` changes only the mapping from point row to sampled source
feature. The permutation is seeded, reproducible, saved, and restricted to
eligible points within the same object. It does not change the visible points,
feature multiset, trajectories, target coordinates, masks, or counts.

## Payloads

Two three-channel source grids are tested at 60x104.

### Coordinate identity

- channel 0: normalized latent X;
- channel 1: normalized latent Y;
- channel 2: an asymmetric nonlinear XY pattern.

It checks XY/HW orientation and confirms that shuffling point identity changes
the carried spatial identity on real trajectories.

### Initial RGB proxy

The saved `frame_initial.png` follows the verified RealWonder preprocessing:

```text
512x512 RGB
-> PIL bilinear resize to 832x832
-> vertical crop [176:656] to 480x832
-> area pool to [3,60,104]
```

Future saved simulation renders use the same conversion as a comparison target.
They are geometry-aligned coarse RGB proxies generated by RealWonder's point
rendering path. They are not real future-video ground truth. Image error is
computed only on the intersection of transport coverage and target point
support.

## Synthetic correctness tests

Nine hard-transport tests pass:

1. identity transport restores occupied source features;
2. horizontal translation moves features in X;
3. vertical translation moves features in Y without XY/HW swaps;
4. points sharing a source cell remain separate and can diverge later;
5. multiple target contributions are averaged rather than summed;
6. out-of-frame points are dropped without boundary pollution;
7. Correct and Shuffled differ on a nonuniform grid but share coverage;
8. shuffle is seed-reproducible and never crosses object boundaries;
9. outputs are finite, counts are nonnegative integers, and mask equals
   `count > 0`.

Together with the five original trajectory tests and five transport-ready
tests, the complete repository regression is 19/19.

## Real 21-frame results

Correct and Shuffled use identical support in every frame. All fairness checks
are exact:

- transport masks equal;
- contribution counts equal;
- valid-point masks equal;
- source-point masks equal;
- source feature multisets equal;
- coordinate and RGB payload coverage equal;
- saved shuffled permutation differs from identity.

The number of valid carried points is 23,921 in every frame. Spatial coverage
decreases from roughly 20.45% to 17.96% of the full 60x104 grid as deformation
compresses more points into fewer cells. Occupied target cells range from 1,114
to 1,293. Mean contributions per occupied cell range from 18.50 to 21.47, with
a maximum observed count of 100. Count normalization remains finite.

Masked RGB-proxy metrics across all 21 frames:

| Metric | Correct identity | Shuffled identity |
| --- | ---: | ---: |
| mean masked L1 | 0.04146 | 0.22862 |
| mean masked MSE | 0.00653 | 0.07899 |
| mean masked PSNR | 22.04 dB | 11.02 dB |

Correct has lower masked L1 in 21/21 frames. Mean L1 improves by 0.18717,
or 81.87% relative to Shuffled. The result is not caused by a larger mask,
different point count, different feature set, or altered trajectory.

## Visual inspection

Initial, middle, final, and local-zoom comparisons were inspected. Correct
transport retains the white collar, black belt, white front trim, cuffs, and
trouser trim while the identities move with the cloth deformation. Shuffled
transport produces a mixed red-white texture on the identical support. No
systematic left/right or up/down flip, all-black collapse, NaN pattern, or
boundary clamping artifact was observed.

Black holes in the transport visualization are cells with no contribution.
They remain explicit through `transport_mask` and are not filled or dilated in
this first version.

## Scientific boundary

Proved by code and current results:

- the hard nearest-cell operator is numerically and geometrically correct;
- persistent identity outperforms shuffled identity for this saved coarse-RGB
  proxy under strictly matched coverage;
- local RGB identities visibly follow the real Santa point trajectories.

Positive but insufficient for a paper-level conclusion:

- the large Correct/Shuffled proxy gap suggests geometry identity is useful for
  local appearance transport on this one wind-driven cloth scene.

Not validated:

- that the same behavior holds for Wan VAE latent channels;
- that transported conditions improve generated future videos;
- robot action, robot-cloth contact, or granular-sand interaction;
- generalization to other cloth objects, actions, views, or real videos.

The checkpoint-free gate is passed. The subsequent gated Wan VAE-only probe is
now complete and is reported in `docs/stages/06_wan_vae_transport.md`. A
complete video model was not downloaded as part of either stage.
